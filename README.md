# JobApply AI 🚀

> **Personal AI-powered job application automation** — analyze LinkedIn job posts, match resumes with Google Gemini AI, generate personalized emails, and send via Gmail API.

---

## Features

- 📄 **Resume Library** — Upload PDFs once; AI parses them automatically
- 🔍 **Job Analysis** — Paste descriptions or LinkedIn URLs; Gemini extracts company, role, skills, recruiter info
- 🏆 **Auto Resume Matching** — Gemini ranks all your resumes and picks the best one for each job
- ✉️ **Email Generation** — Personalized, professional application emails generated by Gemini
- 📧 **Gmail Integration** — Send emails directly via Gmail API with resume attached
- 🔗 **LinkedIn OAuth** — Access authenticated job posts when public scraping is blocked

## OAuth Setup

### Google (Gmail API)

1. Go to [Google Cloud Console](https://console.cloud.google.com)
2. Create a new project or select existing
3. Enable **Gmail API** from API Library
4. Go to **Credentials → Create Credentials → OAuth 2.0 Client ID**
5. Application type: **Web application**
6. Add authorized redirect URI: `http://localhost:5000/api/gmail/callback`
7. Copy **Client ID** and **Client Secret** to `.env`

> **Scopes required:** `https://www.googleapis.com/auth/gmail.send`

### LinkedIn (Optional — for authenticated job fetching)

1. Go to [LinkedIn Developer Portal](https://www.linkedin.com/developers/apps)
2. Create a new app
3. Go to **Auth → OAuth 2.0 settings**
4. Add redirect URL: `http://localhost:5000/api/linkedin/callback`
5. Request scopes: `r_liteprofile`, `r_emailaddress`
6. Copy **Client ID** and **Client Secret** to `.env`

### Google API Key (Works with Gemini AND Claude)

1. Go to [Google AI Studio](https://ai.google.dev/)
2. Create a new API key
3. Add to `.env` as `GEMINI_API_KEY`
4. This single key works with both:
   - **Google Gemini 1.5 Flash** (default)
   - **Claude Sonnet 4.6** (set `AI_PROVIDER=claude`)

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/resumes/upload` | Upload PDF resumes |
| `GET` | `/api/resumes` | List all resumes |
| `DELETE` | `/api/resumes/:filename` | Delete a resume |
| `POST` | `/api/job/analyze` | Analyze job description |
| `POST` | `/api/job/match-resumes` | Match resumes to job |
| `POST` | `/api/email/generate` | Generate email with Gemini |
| `POST` | `/api/email/send` | Send email via Gmail |
| `GET` | `/api/gmail/auth` | Start Gmail OAuth |
| `GET` | `/api/gmail/callback` | Gmail OAuth callback |
| `GET` | `/api/gmail/status` | Check Gmail connection |
| `GET` | `/api/linkedin/auth` | Start LinkedIn OAuth |
| `GET` | `/api/linkedin/callback` | LinkedIn OAuth callback |
| `POST` | `/api/linkedin/fetch-job` | Fetch LinkedIn job page |

---

## Workflow

1. **Upload resumes** (once) → stored in `/backend/resumes/` and parsed by Gemini
2. **Paste a job description** or LinkedIn URL → Gemini extracts key details
3. **AI automatically matches** your resumes to the job → best one selected
4. **Connect Gmail** with one click (OAuth 2.0)
5. **Generate email** → Gemini writes a personalized email using job + resume data
6. **Edit if needed** → click Send → email + resume PDF sent via Gmail API
